## Project Five: JSP Login Page OR Twitter Comparison

(Note: You only need to choose one of these. Plans for both are provided below.)

**Option A: JSP Login Page**

* **Task 1:** Set up the development environment by installing Apache Tomcat and creating a SQL database with an ODBC DSN.


* **Task 2:** Build a registration page accepting at least 5 user inputs (including first/last name, photo, DOB, User ID, and password).


* **Task 3:** Build a login page with User ID and password inputs, plus a link for forgotten passwords.


* **Task 4:** Create a landing page displaying today's date, a personalized welcome message, the user's photo, and a logout option.


* **Task 5:** Implement JDBC connectivity to validate login credentials against the database and set up error/confirmation handling across a cohesive UI theme.



**Option B: Twitter Comparison**

* **Task 1:** Set up a web application project and obtain Twitter API access.


* **Task 2:** Implement an API or scraping tool to dynamically identify competitors without hard-coding them.


* **Task 3:** Build the frontend with inputs for "Name of the Company" and "Category/Content".


* **Task 4:** Develop backend logic to run sentiment analysis on fetched tweets.


* **Task 5:** Display analysis on the frontend via a graph or table comparing the company to its competitor across 5-6 parameters (e.g., tweet count, followers, positive/negative sentiment).
